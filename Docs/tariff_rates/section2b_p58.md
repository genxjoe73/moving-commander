## Item 160 — Elevator, Stair Carry, and Excessive Distance Carry Charges

Per cwt (per 100 lbs of shipment weight).

| Charge | Rate Per Cwt |
|---|---|
| Elevator (any number of flights) — per each elevator used | $4.65 |
| Stairs (inside or outside) — per each flight | $3.30 |
| Long Carry — per each carry | $3.30 |

A "flight" inside a building = 8+ steps; outside flights are computed from total step counts (page 41 governs).
A "long carry" = each 50 ft (or fraction) beyond the first 75 ft from the vehicle.
