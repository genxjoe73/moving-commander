# Item 130 — Weight Additives (page 57, Item 130 concluded)

When a shipment includes any of these items, max transportation charges are based on net scale weight + Weight Additive.

| Article | Weight Additive |
|---|---|
| Airplanes, Gliders (except Hang Gliders), Ultralights | 120 lbs per linear foot of fuselage total length |
| Camper Shells (any size, not mounted on trucks) | 700 lbs |
| Boats and Sailboats <14 ft (mounted/unmounted on trailers) | 700 lbs |
| Canoes, Skiffs, Rowboats, Dinghies, Sculls, Kayaks ≥14 ft (mounted/unmounted on trailers) | 700 lbs |
| Boats and Sailboats ≥14 ft | 2,500 lbs |
| Boat Trailers (any length) | 1,600 lbs |
| Travel Camper Trailers / Mini-Mobile Homes (other than Utility/Pop-Up Trailers) | 7,000 lbs |
| Campers (excluding Camper Shells) not mounted on trucks | 7,000 lbs |
| Horse Trailers | 7,000 lbs |

## Notes
- Note 2: Multi-bulky shipments — total Additive = sum of individual additives.
- Note 3: Disregard fractions of a foot when measuring length.
- Note 4: Boats etc. measured straight-line transom-to-bow centerline. Manufacturer's "length overall" governs.
- Note 5: Bulky charge or Weight Additive applies whether assembled or disassembled. Additives based on longest disassembled part.
- Note 6: Loading/Unloading charges include handling and blocking. Apply each time loaded/unloaded, including SIT (except for carrier convenience).
- Note 7: Item 130 charges apply for movement into and out of storage-in-transit.
- Note 8: Item must fit standard loading van.
- Note 9: All motorized vehicles must be drivable at loading/unloading.
